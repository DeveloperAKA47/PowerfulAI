处理纯表单数据：Form
Form 是 FastAPI 提供的一个标记函数。
它的作用是：告诉 FastAPI，这个参数的值要从表单编码的数据中提取（而不是从 URL 查询参数或 JSON 请求体中提取）。

File：是一个标记函数，告诉 FastAPI“这个参数是一个文件字段”。它必须和类型声明配合使用。
UploadFile：是一个类，代表上传的文件。它提供了文件名、MIME 类型、异步读取等方法，并且文件内容以临时文件形式存储，不会一次性占满内存。

多文件上传
images: list[UploadFile] = File(...)：接收多个文件，字段名 images。
enumerate(images) 给每个文件编号，防止重名。
每个文件都用 shutil.copyfileobj 保存。

响应模型
作用：声明接口返回给客户端的数据结构，FastAPI 会自动：
过滤掉不在响应模型中的字段（保护敏感数据）
转换数据类型（如 datetime 转字符串）
生成 JSON Schema 并显示在交互文档中
